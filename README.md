# Privacy Policy (Point Plus)

Privacy policy and terms of service for the **Point Plus** rewards app.

This repository stores the public-facing policy text for Point Plus. Content lives in `index.md` and is intended for GitHub Pages hosting.

## Purpose

Documents how the Point Plus loyalty program works and how user data related to rewards is handled. App name: Point Plus (Version 1.0). Last updated: December 2025.

## What the Content Covers

1. **About the program** — Points are earned through qualifying purchases, promotions, or activities described in the app.
2. **Point system and usage** — Point awards are determined by Point Plus and may change; points have no cash value and cannot be sold, transferred, or exchanged for currency; points are tied to the user account.
3. **Data collection and privacy** — Data needed to manage reward points and improve the app experience is collected under this policy.
4. **Contact** — Point Plus, email: pointplus@gmail.com
